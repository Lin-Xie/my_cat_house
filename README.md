# 我的橘猫小屋

在像素小屋里领养一只橘猫。你可以摸摸它、陪它玩、一起种盆栽，也可以和它聊天。**第一次体验只需要一台电脑和浏览器。按下面的步骤安装 Node.js 并启动小屋，领养和玩耍都不需要 API Key。**

## 第一次打开小屋（Windows）

### 1. 从 GitHub 下载并解压

1. 在本项目的 GitHub 首页，找到文件列表上方的绿色 **Code** 按钮。
2. 点 **Code → Download ZIP**。下载完成后，在浏览器的下载记录里点文件旁的文件夹图标，找到 ZIP 压缩包。[GitHub 下载说明](https://docs.github.com/en/repositories/working-with-files/using-files/downloading-source-code-archives)
3. 右键压缩包，选 **全部提取**（或「全部解压缩」），选一个方便下次找到的位置，点 **提取**。
4. 打开解压后的文件夹。如果里面只有一层同名文件夹，再打开一层。**当你能同时看到 `server.mjs`、`web` 和 `README.md` 时，就找对了。** 保留这个文件夹窗口，稍后从这里启动。

### 2. 安装 Node.js（只需一次）

1. 打开 [Node.js 官方下载页](https://nodejs.org/zh-cn/download)，选择 **Windows** 和标有 **LTS** 的版本，下载 **Windows 安装程序（.msi）**。项目需要 Node.js **22 或更高版本**。
2. 双击下载好的 `.msi` 文件，按安装向导完成安装。如果电脑已有符合要求的 Node.js，可以直接进行下一步。

### 3. 在项目文件夹里启动服务

1. 回到第 1 步找到的文件夹。单击文件资源管理器顶部的**地址栏**（显示文件夹路径的位置），输入 `cmd`，按 **Enter**。这样打开的命令窗口已经位于项目目录。
2. 输入下面的命令并按 **Enter**，检查 Node.js 版本。看到以 `v22.` 或更高主版本号开头的结果即可继续。

   ```sh
   node --version
   ```

3. 在同一窗口输入下面这行并按 **Enter**。项目没有需要额外安装的运行依赖。

   ```sh
   node server.mjs
   ```

4. 看到 **猫咪小屋  http://127.0.0.1:4317** 就说明启动成功。**让命令窗口保持打开**，可以把它最小化。

### 4. 在浏览器领养猫咪

1. 在刚才启动服务的电脑上打开 [进入我的橘猫小屋](http://127.0.0.1:4317)，也可以把 `http://127.0.0.1:4317` 复制到浏览器地址栏。
2. 第一次进屋会出现领养窗口。给猫咪起个名字。如果希望下次回来收到它的主动问候，可以勾选 **开启自主日记和回访来信**。
3. 点 **领养并开始教程**。点画面里被圈出的猫咪摸摸它，再点食碗喂食。完成当前操作后，教程会带你去下一处。想自己探索就点 **稍后再学**，以后点顶部的 **使用教程** 可以继续。

## 想和猫咪聊天？

1. 准备好模型服务商提供的 **API 基础地址、模型名称和 API Key**。接口需兼容 Chat Completions，模型名称请使用服务商给出的完整标识。
2. 点小屋右上角的 **设置与隐私**，依次填入这三项。如果出现模型下拉框，可以直接选择。只在自己的电脑上勾选 **在此浏览器记住密钥**，勾选后密钥会以明文保存在本机浏览器中。
3. 点 **测试连接**。看到「连接成功」和模型的回复后，点 **保存**。
4. 在右侧聊天框输入一句话，按 **Enter** 发送，按 **Shift + Enter** 换行。也可以在服务启动后打开[独立回访演示](http://127.0.0.1:4317/#return-demo)，点 **模拟重新进屋**，无需密钥就能看看猫咪怎样接着上次的话题聊。

## 怎么退出，下次怎么回来？

- **退出**：关掉小屋网页，回到运行服务的命令窗口，按 **Ctrl + C** 停止服务。
- **下次回来**：在原来的项目文件夹打开命令窗口，再运行 `node server.mjs`，用同一台电脑、同一个浏览器访问同一地址。猫咪、聊天和小屋进度保存在浏览器中。使用无痕窗口或清除站点数据会影响存档。

## 打不开时，先对照这里

| 你看到的情况 | 怎么处理 |
| --- | --- |
| 输入 `node` 后提示「不是内部或外部命令」 | 完成第 2 步安装，关闭旧命令窗口，再从项目文件夹地址栏输入 `cmd` 打开一个新窗口。 |
| 提示 `Cannot find module`，末尾是 `server.mjs` | 确认已经解压，并在能看到 `server.mjs` 的那一层文件夹打开命令窗口。 |
| 浏览器提示「无法访问此网站」 | 回到第 3 步，看命令窗口是否仍开着，并确认浏览器地址是 `http://127.0.0.1:4317`。 |
| 提示 `EADDRINUSE` 或端口 4317 已被占用 | 先打开小屋地址。如果小屋已出现，直接使用即可。如果显示其他服务，先关闭占用该端口的程序，再启动小屋。 |
| 能摸猫，但测试模型连接失败 | 在「设置与隐私」查看具体提示，核对 API 地址、模型名和密钥，确认服务账户可用后重新测试。 |

- 在猫咪档案开启「自主日记和回访来信」后，回屋时聊天里会收到发芽、长叶、开花或成熟的消息；离开几天只报最新变化，安静时段暂缓。植物长成后可在花盆内点「种下一盆」，提交新种子和名字后才替换，旧回忆保留。

- 设置与隐私中填写兼容 Chat Completions 的 API 地址、模型和密钥，可以测试连接。默认密钥只在页面内存；勾选记住后以明文留在该浏览器。导出只包含小屋存档，不含 API Key。清除本机数据前会请求确认。
- 当前版本会在本浏览器恢复最近 400 条聊天消息；每次续聊带上最近六条普通消息，本地安全回应不会作为模型上下文发送。旧版未保存的完整对话无法追溯。聊天会向所选供应商发送本轮与近期对话、猫的当前状态、至多五条相关的已收录聊天回忆和最近三条已收录的照料记录。默认在本地匹配；另行开启模型语义查找后，每次有候选的聊天会额外发送本次问题和最多 32 条确认摘录供排序，失败回退本地。可以在「猫咪日记 → 管理记录」中逐条忘记；主动删除后仅保留标识和删除时间，关联日记或来信也移除。最近记录上限 180 条，优先保留对话回忆。
