# 我的橘猫小屋

一个在电脑浏览器里养橘猫的小项目。可以摸猫、喂食、玩玩具、种盆栽，查看猫咪的成长和日记。配置模型 API 后，也可以和它聊天。

日常互动不需要 API Key。猫咪、聊天记录和小屋进度保存在当前浏览器里。

## 下载与打开

Windows 10 / 11 的 x64 电脑可以在 [Releases 下载页面](https://github.com/Lin-Xie/my_cat_house/releases/latest) 的 **Assets（附件）** 中下载 `我的橘猫小屋.exe`。双击即可在默认浏览器中打开，不用安装 Node.js，也不会弹出终端窗口。

同一页面提供使用说明和 `SHA256SUMS.txt` 校验文件。只想使用小屋，下载 EXE 即可；`Source code` 是给开发者的源码包。

第一次打开要解包内置运行时，稍等片刻即可。可以把这个 EXE 放在桌面或其他方便找到的位置，不需要附带源码文件夹。

关闭网页后，小屋仍在右下角托盘运行。右键猫咪图标，可以重新打开或退出；看不到图标时，点任务栏的向上箭头。重复双击 EXE 会打开已有小屋，不会启动多个服务。

## 第一次进屋

1. 给猫咪取名。想收到回访问候，可以勾选「开启自主日记和回访来信」。
2. 点击「领养并开始教程」，按提示摸猫、喂食、试试玩具。也可以先跳过，以后从「使用教程」继续。
3. 想聊天时，打开右上角「设置与隐私」，填写服务商提供的 **API 基础地址、模型名称、API Key**。接口需兼容 Chat Completions。点击「测试连接」，成功后保存。

聊天可能产生服务商的 API 费用。不配置模型也可以养猫、玩耍和种植物。

## 存档与隐私

请继续使用同一个浏览器。EXE 与源码版使用相同地址 `http://127.0.0.1:4317`，原来的浏览器存档可以继续使用。无痕窗口、清除站点数据或更换浏览器，都可能让你看不到原来的存档。

「设置与隐私 → 本机数据」可以导出小屋数据；当前界面没有导入功能。API Key 默认只保留在当前页面内存中；勾选「在此浏览器记住密钥」后会以明文保存在浏览器里。导出数据不包含密钥。聊天会把当前消息、近期对话和相关记忆发送给你配置的模型服务。

程序会将内置运行时解包到 `%LOCALAPPDATA%\OrangeCatRoom\runtime`，不要求管理员权限，也不添加开机启动项。退出小屋后可以删除 EXE 和这个运行时目录；这不会清除浏览器存档。

## 打不开时

| 情况 | 处理方法 |
| --- | --- |
| 浏览器没有自动打开 | 右键托盘猫咪图标，选择「打开小屋」，或访问 <http://127.0.0.1:4317>。 |
| 提示端口 4317 被占用 | 先退出旧版小屋或占用该端口的程序，再打开。 |
| Windows 显示未知发布者 | 当前 EXE 未做代码签名。请先核对文件来源和发布包里的 SHA256SUMS.txt，不要运行来源不明的文件。 |
| 启动时报错 | 查看弹窗提示；错误详情保存在 `%LOCALAPPDATA%\OrangeCatRoom\launcher.log`。 |
| 模型连接失败 | 按设置页的提示核对 API 地址、模型名称、密钥和账户状态。 |

## 开发与环境配置

修改源码需要 Node.js 22 或更高版本，可从 [Node.js 官网](https://nodejs.org/zh-cn/download) 安装。在项目根目录运行 `node server.mjs`，再打开 <http://127.0.0.1:4317>。不需要 `npm install`；退出服务时按 Ctrl+C。

重新生成 Windows EXE 需要官方 Node.js v24.16.0 Windows x64 运行时和 Windows 自带的 .NET Framework C# 编译器，具体步骤见 [Windows 构建说明](packaging/windows/README.md)。用户配置模型地址和密钥时直接使用小屋中的设置界面，不需要修改环境文件。

## 仓库内容

- `web/`、`server.mjs`：小屋界面、生活与记忆规则、本机服务，包含回访演示。
- `packaging/windows/`、`scripts/`：EXE 启动器、构建配置、打包脚本及第三方许可。
- `tests/`：成长与记忆逻辑测试、Windows EXE 验收，不随 EXE 分发。

运行逻辑测试：`node --test tests/companion.test.mjs tests/life.test.mjs`。

构建后运行 EXE 验收：`powershell -NoProfile -ExecutionPolicy Bypass -File tests/windows-package.ps1`。默认使用独立端口 14317；若被占用，可加 `-Port 14318`。这些测试不需要 Playwright。

构建产物生成在 `dist/windows/`，通过 Releases 分发，不提交到 Git。`.build/` 是可删除的中间文件；本地文档、设计资料、视频和海报也不纳入仓库。
